## Event Description

Efficient data movement is key to effective HPC usage. This workshop provides a hands-on introduction to transferring data within HPC systems. Gain insights into tools, techniques, and troubleshooting tips to handle large datasets with confidence.

 **Target audiences:** Graduate/undergraduate students, postdocs, research computing staff, faculty

 **Pre-requisite:** Basic Linux system commands.

 **All workshops have a hands-on component:** To fully participate, attendees are required to:

 1. Have a laptop with a stable internet connection.
2. Have a basic understanding of using a command-line interface (terminal/shell).
3. Have a working SSH client installed on their laptop. (e.g., PuTTY for Windows, Terminal for
 macOS/Linux)

## Event Description

The Big Ten Academic Alliance [(BTAA) Geoportal](https://geo.btaa.org/) is a discovery tool that connects scholars to regional geospatial resources including GIS datasets, web services, and digitized historical maps. Rutgers is a member of the BTAA Geopatial Information Network (BTAA-GIN) and contributes to this endeavor.

 In this introductory workshop to the BTAA Geoportal, we'll explore the varieties of regional resources, how to search the portal, included documentation and support, as well as discuss how the Geoportal might enhance your research.

## Event Description

REDCap is a flexible, robust, secure, web-based, survey and database platform used for research studies, operational reviews, and more.

 Join us for an introduction to REDCap workshop, designed for new or novice users.

 This hands-on session will guide you through essential terminology, Rutgers REDCap access, basics of project creation using forms/surveys, and best practices recommendations.

 No REDCap experience is expected.

## Event Description

A Geographic Information System (GIS) can be a very useful tool for your research by incorporating location when exploring questions. In this short, interactive workshop, we will work through various GIS data tools including data table join operations and spatial data management analyses.

 Make sure to [register for an ArcGIS Online account](https://rutgers.maps.arcgis.com/home/index.html) before the start of the workshop.

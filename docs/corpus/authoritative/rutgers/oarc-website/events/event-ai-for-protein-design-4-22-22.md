## Event Description

**Amarel account:** [**Apply here as soon as possible**](https://oarc.rutgers.edu/amarel-cluster-access-request/). **You must have an Amarel account set up before the workshop.**

 **VPN setup:** You have to be connected on Rutgers' network or [**be on VPN**](https://soc.rutgers.edu/vpn/) to access Amarel resources.

 **SSH setup:** Windows users must install an SSH client like [**PuTTY**](https://www.putty.org) or [**MobaXterm**](https://mobaxterm.mobatek.net). Alternatively, Windows 10 users can install the complete [**Windows Subsystem for Linux**](https://docs.microsoft.com/en-us/windows/wsl/install-win10).

 **Workshop content:** This workshop will present a broad overview and hands-on session on how Artificial Intelligence/Machine Learning (AI/ML) methods are being used for de novo protein structure prediction and provide hands-on experience with both AlphaFold2 and RoseTTAFold.

 ****Note****Just observing is welcome, but to participate in hands-on activities, you must have an Amarel account setup before the workshop. Please complete our [**web-based form**](https://oarc.rutgers.edu/amarel-cluster-access-request/) at least 24 hours before the workshop (do this as soon as possible).

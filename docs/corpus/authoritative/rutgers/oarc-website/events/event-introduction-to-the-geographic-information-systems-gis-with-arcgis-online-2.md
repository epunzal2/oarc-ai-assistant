## Event Description

A Geographic Information System (GIS) can be a very useful tool for your research by incorporating location when exploring questions.

 In this short, interactive workshop, we will focus on ArcGIS Online basics, explore the interface, add and visualize data. We will explore the analysis tools, hosted feature services, collaboration and sharing. Previous knowledge of geographic information systems is not expected.

 Make sure to [register for an ArcGIS Online account](https://rutgers.maps.arcgis.com/home/index.html) before the start of the workshop.

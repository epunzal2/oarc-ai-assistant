## Event Description

A Geographic Information System (GIS) can be a very useful tool for your research by incorporating location when exploring questions.

 In this short, interactive workshop, we will focus on the open source geographic information system: QGIS3. We will explore the interface, add and visualize data, create a map layout, explore plugins and support. Previous knowledge of GIS is not expected.

 Please make sure to [download QGIS here](https://www.qgis.org/):

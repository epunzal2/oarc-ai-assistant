## Event Description

This session introduces the R statistical software environment, basic methods of data analysis, and the **"tidyverse."** While R is much more than the tidyverse, the development of the tidyverse packages, led by RStudio, has provided a powerful and connected toolkit to get started using R. Note that graphics and data manipulation are covered in subsequent sessions.

## Event Description

A Geographic Information System (GIS) can be a very useful tool for your research by incorporating location when exploring questions.

 In this short, interactive workshop, we will focus on ArcGIS Pro basics, explore the interface, add and visualize data, create a map layout which we can either export as a PDF or share as a web map. Previous knowledge of geographic information systems (GIS) is not expected.

 Make sure to [register for an ArcGIS Online account](https://rutgers.maps.arcgis.com/home/index.html) before the start of the workshop.

 Please also download the ArcGIS Pro application. This requires a Microsoft Windows operating system. Details and information for installing the application may be found at the [Rutgers Software Portal](https://software.rutgers.edu/product/3663). The application is also available through the [Rutgers Virtual Computer Labs](https://it.rutgers.edu/virtual-computer-labs/). An ArcGIS Online account is needed to log into ArcPro.

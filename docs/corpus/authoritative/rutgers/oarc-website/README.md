# OARC Website Corpus

Markdown capture of sitemap-listed pages from the Rutgers Office of Advanced Research
Computing website.

## Provenance

- Source site: https://oarc.rutgers.edu/
- Sitemap index: https://oarc.rutgers.edu/sitemap.xml
- Fetched on: 2026-05-22
- Scope: same-host `oarc.rutgers.edu` URLs listed in the Yoast/WordPress sitemap index.
- Exclusions: `robots.txt` disallowed paths and off-host links.
- Transformation: WordPress/Divi HTML and event metadata converted to Markdown; archived
  meeting URLs/password-like values are redacted when encountered.

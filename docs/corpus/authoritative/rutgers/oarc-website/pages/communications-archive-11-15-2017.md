## Troubleshooting a Scheduling Problem

Galen Collier Wednesday, November 15, 2017 at 3:17 pm

Good Afternoon All,

We've encountered a problem with the load on our SLURM job scheduling system and we're currently tuning some settings to resolve it. This issue may already be resolved, but we are monitoring the system to ensure that it's stable.

Please note: if you are submitting very large numbers of jobs, using a job array is a much more efficient option than scripting the submission of a large collection of standalone jobs. More information about using job arrays can be found here: [https://slurm.schedmd.com/job_array.html](https://slurm.schedmd.com/job_array.html) and there is a simple example in /projects/oarc/examples/array_job.

Of course, let us know if you encounter problems or if you need help.

Galen

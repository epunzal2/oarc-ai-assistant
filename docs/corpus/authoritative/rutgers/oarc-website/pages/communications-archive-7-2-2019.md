## Purging Files from /scratch + Storage Software update on July 10

Galen Collier

Tuesday, July 2, 2019 at 12:43 pm
OARC Research Computing Users,

(1) As announced on June 10, files sitting unused for 90 days in the Amarel and Perceval /scratch file systems will be automatically deleted. This process will begin in September.

(2) We are shifting to a new /scratch filesystem on July 10 and all nodes must be updated with new GPFS software. Doing so will require a 6-hour downtime for the entire system (July 10, 11:00am to 5:00pm ET). Data currently stored in /scratch will be moved to the new /scratch filesystem, so there is no need for users to move data. Jobs whose run time intersects with this maintenance window will remain in a "pending" state until the system is returned to service.

Please let us know if you have questions or concerns.

Galen

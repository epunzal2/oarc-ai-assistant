## Maintenance now complete for Amarel, Perceval, NM3 (+ important notes re: /scratch, /home)

Galen Collier Friday, October 12, 2018 at 2:20 pm

OARC Research Computing Users,

Maintenance for the Amarel, Perceval, and NM3 systems is now complete. Thanks for your patience!

The maintenance ran a few hours longer than expected because it comprised an unusually complex set of tasks spanning multiple campuses (more of an overhaul to improve performance for a widely distributed, rapidly growing system). Some debugging is still underway.

Details about the maintenance work that was completed and further updates can be found at [https://oarc.rutgers.edu/systems-status](https://oarc.rutgers.edu/systems-status)

** Important notes: (1) The /scratch filesystem has been redesigned to improve performance across our various campuses. Files that were previously stored in /scratch can be found in /oldscratch. The contents of /oldscratch will be available until December 14, so please move any data you wish to save.

(2) The contents of /home/projects can now be found in /projects (i.e., the link to /projects under /home has been removed).

As always, please let us know if you have questions or if you encounter problems: [help@oarc.rutgers.edu](mailto:help@oarc.rutgers.edu)

Galen

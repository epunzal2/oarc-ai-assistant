## Major Maintenance for Amarel, Perceval, NM3 (Oct 5 - 11)

Galen Collier Wednesday, October 3, 2018 at 3:55 pm

OARC Research Computing Users,

This is a reminder of the upcoming maintenance window scheduled to begin Friday, Oct 5 @ 6pm and end Thursday, Oct 11 @ 6pm.

The Amarel, Perceval, and NM3 systems will be offline with no access to their associated filesystems.

This will be a relatively long maintenance window because there are many major tasks to be completed:

- Connecting the new research network across all campuses (Camden, Newark, RBHS, New Brunswick) - Network configuration adjustments to enable a consistent VLAN across all campuses - Configuration changes for our GPFS filesystems across all campuses - GPFS Storage Server updates to support the new distributed configuration - Cloud federation-related configuration changes - SLURM updates and other related software updates

Jobs scheduled for a timeframe that overlaps with this maintenance window will be held in 'pending' status. We anticipate having those jobs resume queuing and running as submitted when the maintenance is complete.

Please let us know if you have questions or concerns.

Galen

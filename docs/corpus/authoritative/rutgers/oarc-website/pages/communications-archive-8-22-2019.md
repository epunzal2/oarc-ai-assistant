## Purging Files from /scratch

Galen Collier Thursday, August 22, 2019 at 4:23 pm

OARC Research Computing Users,

As announced previously, files sitting unused for 90 days in the Amarel and Perceval /scratch file systems will be automatically deleted. This process will begin in September.

Some basic information about transferring data from Amarel is available here: [https://sites.google.com/view/cluster-user-guide/amarel#h.t618y9lhk7u9](https://sites.google.com/view/cluster-user-guide/amarel#h.t618y9lhk7u9)

In addition, if you are interested in learning about steps for setting-up rclone for transferring data from Amarel to box.rutgers.edu (free unlimited storage for the Rutgers community), let us know.

Please note that transferring data across the campus network from any source can be a very slow process. Don't wait to start moving your data.

Galen

## **Data Storage**

The Amarel model regarding storage pricing and policy of terms has changed with phase Clark. Amarel owners may purchase project storage consistent with research needs for ~$123/TB per year ($0.12/GB per year). A 1TB GPFS fileset is included with every Amarel node purchased. A fileset is a subtree of a file system namespace that in many respects behaves like an independent file system and can be shared among all accounts supported by an owner. A 100GB home directory is created for each owner-supported user account. All included and purchased storage includes backup, but high-speed scratch is not backed up.

The high-performance /scratch filesystem is local to the compute nodes that a job uses. Amarel GPFS Storage is distributed across [CICnet, the Rutgers research network](https://oarc.rutgers.edu/resources/cicnet/).

For further information on data storage usage and best practices, see the [**File Set section**](https://sites.google.com/view/cluster-user-guide#h.7ts4ih7duycc) of the User Guide.

## Amarel & Perceval Lmod Upgrade

Galen Collier Tuesday, October 23, 2018 at 8:32 pm

OARC Research Computing Users,

On Thursday, Oct 25 at noon (ET), we will upgrade the version of Lmod used on Amarel and Perceval from version 6.0 to 7.8. In case that name sounds unfamiliar, Lmod is the tool we use to manage software modules (listing and loading modules). This change will be completed within about 10 minutes and it should go unnoticed by most users.

Here is a link to the documentation for Lmod: [https://lmod.readthedocs.io/en/latest](https://lmod.readthedocs.io/en/latest)

Some notable changes:

- The default version of java (i.e., the module loaded with the 'module load java' command) will be changed to 1.8.0_171 - The Lmod "family" directive will be added to the modulefile for some modules to more strictly prevent potentially conflicting modules from being loaded

Of course, if you notice any problems with the loading of modules, please let us know.

Galen

## Amarel CCB nodes and storage deprovisioning

Amarel CCB Nodes and Storage Users,

The nodes comprising the **ccb_1** job partition and the storage file set at **/projects/ccb** have been in-service since July 2017 and they're about 3 months overdue for retirement. We must now remove those resources from service.

On Thursday, Nov. 18 (two weeks from today) at 12:00 PM ET, the **ccb_1** job partition will no longer accept jobs and it will be removed once its queue has cleared.

On Thursday, Dec. 2 (four weeks from today) the **/projects/ccb** storage file set will be purged and removed. There are currently about 72 GB of data there now.

Please adjust plans for any ongoing work accordingly and remove any data you wish to keep well before Dec. 2nd.

If you have questions or need help, let me know.

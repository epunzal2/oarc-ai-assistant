## UPDATE: HPCC and Perceval Maintenance

Eric Marshall Tuesday, June 6, 2017 at 1:55 pm

Dear users, The OARC clusters, Perceval, HPCC, and Hadoop are will remain unavailable for a little while longer while we complete problem remediation. As you may know, we are in the process of transitioning the recently installed Amarel cluster to regular production status. In order to provide an efficient and coherent environment for OARC's user community, Amarel uses much of the same infrastructure associated with Perceval, HPCC, and Hadoop.

During the integration of Amarel into the OARC environment, we encountered a few problems with the high speed Infiniband network that connects all of the compute and storage elements. This was likely compounded by a problem that developed with the General Parallel File System (GPFS) which supports all /home /scratch and shared storage. We believe we have resolved the GPFS problem and are now verifying the health of the overall file system. At the same time, we are working to resolve any remaining Infiniband issues. We expect the system to be available sometime tomorrow (June 7th). We will advise you if there any changes to this schedule.

Thank you for your patience and apologize for the inconvenience this has caused.

Regards, OARC technical and scientific team

# Authoritative Corpus

Use this tree for Rutgers OARC, Rutgers-wide research computing and storage, and
Amarel-specific documentation.

- Prefer official OARC user guides, local runbooks, scheduler/account guidance, and any internal
  notes that directly describe Amarel behavior.
- If a document describes a command, module, partition, filesystem path, account rule, or support
  workflow that is specific to Amarel, it belongs here.
- If a document describes Rutgers-managed research storage, data, or compute services outside
  Amarel, keep it under a Rutgers-scoped subdirectory such as `rutgers/`.
- Rutgers-wide OARC web sources that include both Amarel and non-Amarel content should remain under
  `rutgers/` with local provenance notes.
- If a document is generic software documentation rather than site-specific policy, place it under
  `../reference/` instead.
